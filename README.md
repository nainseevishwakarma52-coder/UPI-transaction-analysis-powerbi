# UPI Transactions & Balance Analysis Dashboard (Power BI)

## Project Overview
Interactive Power BI dashboard designed to analyze financial transactions, customer demographic trends (age groups), and remaining account balances.

## Key Features
- **Data Profiling & ETL:** Cleaned and profiled raw financial transaction datasets.
- **Interactive Visualizations:** Line charts for time-series trends and Matrix visuals for account-level breakdowns.
- **Dynamic UX/Navigation:** Integrated page bookmarks to toggle views between transaction summaries and remaining balances.
- **Advanced Slicers:** Synchronized cross-page slicers with custom formatting for seamless multi-dimensional filtering.
- **Conditional Formatting:** Applied custom KPI formatting to highlight balance thresholds.

## Tech Stack
- Power BI Desktop
- Power Query
- DAX
